How criteria use existing collections

Saving queues a background recalculation using retained successful full collections. 0 days uses the latest confirmed conditions; higher values count from the earliest observation in the current unbroken sequence. Unknown/excluded checks, configuration changes and excessive gaps break the sequence. Existing review notes and historical snapshot assessments stay unchanged. Zero-hit rules require fresh zero-counter evidence; an unchanged positive counter does not establish inactivity.

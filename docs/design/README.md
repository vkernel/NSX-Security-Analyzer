## Evidence folders

Each folder holds screenshots and browser-check results captured with synthetic
data for the review named in its title (for example
`firewall-reference-review-2026-11-04`, `membership-review-2026-11-05`,
`vm-confirmed-references-2026-11-05`). They document what was checked on that
date only.

# Ten new brand directions · Circuit + Atlas

> **Historical record.** This document describes the design or implementation at the time it was written. Current code, tests and the main documentation take precedence.

Ten standalone design alternatives for NSX Security Analyzer, based on the compact operational precision of Circuit and the spacious application landscape of Atlas. The original five directions remain available in [the earlier exploration](brand-directions/index.html).

## Recommended shortlist

**Relay** is the strongest balance of Circuit and Atlas: dark, composed, mint accents and a wide workspace. **Northstar** is the best light alternative for reading application relationships. **Nexus** is the most approachable option for a shared engineering and approval workspace. Choose **Ion** if you prefer the compact console character of Circuit.

These are archived alternatives for comparison. Relay option 04 was subsequently selected for the shared application shell, with Bridge 06 as its light palette; see [the implementation notes](relay-04-2026-11-03.md).

## Design brief

- **Product:** Understand collected NSX configuration, investigate application relationships and coordinate reviewed changes.
- **Character:** Each direction varies in tone, while keeping operational clarity and accountability.
- **World:** A network operations workspace shared by engineers, owners and approvers.
- **Moments:** Reading application connections; comparing current and proposed group names; entering the workspace.
- **Signature:** Environment, collection time and coverage sit beside the evidence being reviewed. Color emphasizes interaction and selection rather than decorating every panel.

Each direction includes segmentation, naming review, login, and a separate brand and icon specimen. Layout, navigation, density, typography, icon weight, panel geometry and original logo construction vary between concepts. The data and workflows remain comparable so the design choice is easier to assess.

## What you can try

1. Choose a concept and switch between the four screens. Filter the concepts by Circuit-led, Atlas-led or Hybrid.
2. In segmentation, select an application, inspect its rule evidence, open the VM lookup drawer, or open the security matrix.
3. In naming review, search for a group, select rows and review the selection in a drawer.
4. In Brand & icons, inspect the mark, palette, typography and icon treatment together. The download links beneath the preview provide the SVG assets.
5. Compare your two favorites side by side; the concept and screen choices are included in the URL.

Drawers support Escape and restore focus. Mobile navigation opens a task chooser. Desktop maps and tables use contained horizontal scrolling on narrow screens rather than squeezing labels into unreadable columns.

## Boundaries

All examples are illustrative. The previews do not load production data or call the application or NSX APIs. Sign-in does not send or store credentials. Rule creation is a disabled placeholder. Other workflows display their design intent without saving changes.

The map represents collected configuration relationships, not observed traffic or a determination of effective access. VM group choices retain dynamic/static distinctions and the fewest-tag-conditions ordering. Naming corrections remain separate from NSX writes, and cleanup approval remains separate from execution.

This package explores the brand and representative screens. Applying a selected direction to all production pages, validating large real datasets, and testing production authorization remain a later implementation step.

The marks and icon specimens are native SVG assets created for these concepts. The UI uses local system font stacks; Avenir Next and Helvetica Neue fall back to installed sans-serif fonts on other platforms. The downloadable SVG wordmarks use Arial/sans-serif to remain self-contained. Light and dark logo masters use suitable accent contrast for their intended backgrounds.

## Validation

- 60 rendered states: four desktop screens for all ten directions, plus segmentation at 390 px and 320 px. No captured JavaScript errors or document-level horizontal overflow.
- 50 individual screen images, plus two visual overview sheets, a comparison example and the chooser screenshot.
- Browser interaction checks cover VM/group choices, nested evidence drawers, focus restoration, map selection, naming search and bulk selection, brand specimens, login preview behavior, mobile navigation, family filters, shareable URLs and comparison image loading.
- Base palette pairs for body text, muted text, accent links, navigation, active navigation and primary button labels all exceed 4.5:1. This is a token-level check, not a full accessibility certification.
- Production application code was not changed; backend tests are not applicable to these standalone concepts.
